## 범위·방법·단위

원본 초기 `0 [두께].xlsx`의 1–10,000Hz **각30점**과 원 profile/JSON canonical SHA를 고정했다. 명목 창은500/1000/2000Hz 이상이며 실제 사용점은 각각 **573.62–10,000Hz 10점 / 1082.6–10,000Hz 8점 / 2043.4–10,000Hz 6점**이다. bare 세 창과 PEDOT 네 두께의1kHz 창은 기존 fit를 참조했고, PEDOT10/30/50/100nm의500/2000Hz 창만 새로 fit했다. 측정점을 만들거나 빠진 구간·복제 측정·잡음을 추정해 채우지 않았다.

모델은 `Z(f)=Rs+1/[Q(j2πf)^n]`, 상대 복소 최소제곱 가중치는 `1/|Z_measured|`다. Rs는Ω, f는Hz, Q는S·sⁿ, n은무차원이고 SI 원값을 [JSON](window-slots-summary.json)과 LF [CSV](window-slots-summary.csv)에 보존했다. n이 달라지면 Q의 단위 지수도 달라지므로 Q 숫자만 독립 물성처럼 비교하지 않는다. unconstrained는 원801 n-grid/70 golden-section, n∈[0.2,1], Rs≥0/k>0/Q=1/k 알고리즘이다. 여기서 unconstrained는 **전체30점 Re(Z)−Rs≥0 제약을 아직 적용하지 않았다**는 뜻이며 n/Rs/양수 제약까지 없다는 뜻은 아니다.

원30점 중 Re(Z)−Rs<0이면 원 unconstrained 값을 보존하고, 등록된1601 n-grid·Rs≤min(full30ReZ)·k>0 fallback을 창당 최대1회 적용했다. 새 fallback2회는 **50nm/500Hz·50nm/2000Hz**에서만 발생했다. 두 창의 원 Rs는215.562376590354/216.053993251923Ω이고 원 비수동 flag를 그대로 보존했다. 선택 surrogate의 Rs는둘다214.13262432777125Ω의상한, n=0.2의검색하한이다. 이 대체값은 물리 계면·식별가능성·건식 검증 또는 안전성의 통과가 아니다.
