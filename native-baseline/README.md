# Approved Task 1 baseline archive

This data branch preserves one NEW cloud baseline recomputation as an independently downloadable scientific archive. The original 478-file migration package remains unchanged. SHA256, per-file manifest and the local byte-verification receipt are adjacent to the archive. Code and numerical metadata are also frozen inside it.

This is not a recovery of the missing historical fields/potentials, a spatial-convergence or experimental-validation claim, or permission to retire old originals. Other new cloud batches are not backed up on this branch. The research implementation and external-readback receipts are on codex/task1-cloud-restart-20261020.

GitHub release asset upload was blocked by HTTP401 for the configured environment. The archive is below50MB; large multi-run archives remain locally preserved rather than adding gigabytes to Git history.
