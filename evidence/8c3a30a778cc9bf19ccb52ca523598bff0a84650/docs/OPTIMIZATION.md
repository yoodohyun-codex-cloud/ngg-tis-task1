## 수치의 의미와 비교

두 지속 작업을 구분한다. **작업1은 각 출력1 Vpp 고정에서20 mm의 두 반송파 TIS(기본파 포락선 변동 폭)를 최대화**한다. 단일 출력은 이 순위에서 제외하며 격자별 원 TIS 선두를 보존·우선 정밀화한다. 실제 총 RMS와 피부 부담 제한 점수는 보조 비교로 계속 저장한다. **작업2는 흉복부 표면 횡격막 자극 문헌과 현재 팬텀의 전기적 크기 비교**다. 근거는 [DIAPHRAGM_REFERENCES.md](DIAPHRAGM_REFERENCES.md), 구조화된 입력은run/inputs/diaphragm-references.json, 결과는run/diaphragm-comparison.json과GUI에 있다.

작업2의 문헌 mA는 peak/RMS·출력 합산 정의가 불명확하다. 따라서 ‘각 출력 중 최대peak라고 가정’과 ‘각 출력 중 최대RMS라고 가정’을 나누어 전압을 환산한다. 주파수별 실제 출력 전류(비구동50Ω출력에 유입되는 전류 포함)를 복원하고, 모든 주파수의 최대공약수로 정해진 주기에서 peak 하한을 표본 계산한다. 2차 미분 상한으로 표본 사이 오차를 제한해 peak 상한과 필요한Vpp구간을 함께 저장한다. 모든 출력의 소스 개방회로 진폭을 같이 조정하며, 각 출력 중 최대값은 채널 전류의 합계가 아니다. 전기장·전류·계면전압은Vpp에 비례하고, SC/접촉/총전력은Vpp제곱에 비례한다.

문헌의30Hz/200µs 펄스와 현재의kHz지속파/TIS는 같은 자극이 아니다. **환산 Vpp는 횡격막 활성화에 필요한 전압이나 권장 설정이 아니다.** 1/2/5/10/20Vpp 스윕도 고정된 소신호 계면의 공학적 외삽이며, 큰진폭 계면·가열·장비출력가능성은 검증되지 않았다. 실제 흉복부·횡격신경·횡격막 및 막흥분 모델이 없어 고정V/m 활성화 임계값을 설정하지 않는다. 30/50/80Hz 단일출력 추가 해석은 연속파 대조군이고 짧은 이상성 펄스를 재현하지 않는다. 작업1은1Vpp를 유지하며 작업2의 진폭 변화로 바뀌지 않는다.

- **실제 총 E RMS**: 모든 계산 주파수의3차원 복소 전기장 성분을 합성한 장시간 RMS 벡터 크기. 같은 주파수의 출력은 먼저 복소 합산한다.
- **기본파 포락선 변동 폭**(기존 ‘변조 깊이’): 두 기본 반송파의 `max_n 2 min(|n·E1|, |n·E2|)`. 한 방향에서 포락선 진폭의 최댓값−최솟값을 V/m로 구하고 여러 방향을 표본 비교한 값이다. 피부 속 깊이(mm), 실제 비트 주파수 전기장 성분, 신경 활성도가 아니다. 예를 들어 평행한 두 기본파가 각각1 V/m peak라면 포락선은0–2 V/m여서 폭은2 V/m, 장시간 RMS는1 V/m다. 고조파 비트는 이 값에 합산하지 않는다. 단일 출력 대조군에는TIS 변조가 없다.
- **피부 부담 제한**: 같은 격자의 기존 bare 기준보다 최대 접촉 J RMS, SC 손실전력, 전극 계면 손실전력, 최대 계면 전압 RMS를 넘지 않게 모든 출력에 공통축소계수≤1을 적용한다. 실측 안전 한계가 아니며 각 부담 지표의 원 수치도 저장한다.
- **동등 총입력전력**: 출력 전력 합계를 기준 이하로 제한한 별도 비교. 채널·파형을 바꾸며 단순히 전력을 늘린 효과를 구분한다.

원 조건은 각 출력1 Vpp이며, 사각파/삼각파도 동일한 소스 peak-to-peak를 맞춘다. 사각파는 기본파와3차 고조파로 제한한 파형으로 이상적인 사각파가 아니다. EIS는1–10000 Hz이므로 고조파가 범위를 넘는 반송파는 sine만 비교한다. 초기 반송파250/500/1000/2000/3000/5000/8000 Hz, 차이5/10/20/50 Hz를 탐색한다. 팬텀의σ/εr 주파수 분산은 실측되지 않았으므로 기존 상수를 유지한 가정 비교다.

## 입력과 검증

기존 XLSX/MPH와 `tis-java/results/`는 보존한다. CV 원본은 `tis-java/electrode-data/cv-source/pedot cic.pzfx`이며 실제 형식은PCFFGRA4 바이너리다.6개 숫자열의 길이·기록 크기·표시 미리보기·전압 범위를 검증해 두 paired 표를 복원했다. 원본 및 record type/format은run에 보존한다. 이 복원은Prism의 공식XML export와 동일한 보증을 뜻하지 않는다.

CV 단위V/A·노출1 cm²와 공통 명목 scan rate100 mV/s는 사용자 확인이다. 실제 timestamps와 명목/원기록 범위·점수 차이는 미확인이다. CV loop 면적을CSC, CIC, 검증된 안전 전압창으로 바꾸지 않는다. Ag/AgCl/Pt는 기준/상대전극에 관한 사용자 잠정 정보다. 두 표의bare 곡선은 다르다.

## 실행과 재개

새 run:

```sh
python tis-java/explore_tis.py --prepare
```

출력된run 경로로 실행:

```sh
python -u tis-java/explore_controller.py --run tis-java/runs/<run-id> --batch 20 --sync
```

한 배치만 재개하려면 `--once`를 추가한다. lock이 있으면 중복 작업을 시작하지 않는다. 작업 환경이 종료되면 자동 프로세스도 중단될 수 있다. `controller.json`의PID/heartbeat와실제프로세스를함께확인한다. GitHub에 파일이 있다고 프로세스가 살아 있다는 뜻은아니다.

정지 요청을 적용하려면run 폴더에 `STOP` 파일을 만든다. 현재 배치가 끝난 후 멈춘다. 재개할 때 `STOP`을 제거한다.

단계: 초기 격자 탐색 → 선별 후보1.25 mm 정밀화 → 주파수×배치 교차탐색 →3단계 국소 크기/배치 탐색 →0.625 mm 및접촉 모델 민감도 확인. 유한 후보군의 선두는 전역 최적의 증명이 아니다. 결과의 물리적 해석이 측정 부재나 격자/접촉 불확실성에 막히면 명시적으로 보고하고 필요한 측정을 요청한다.
