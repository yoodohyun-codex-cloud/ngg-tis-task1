# 초기 bare NGG 임피던스 보정 후 TIS 결과

계산 ID: ngg-initial-20261017-01

## 전해액 직렬저항 분리

초기 bare NGG의 0.1× PBS 3전극 EIS를 사용했다. 노출 면적은 1 cm²다.
1–10 kHz 구간(실제 1082.6–10000 Hz, 8점)에
`Z = Rs + 1 / (Q (jω)^n)`을 상대 복소오차 최소제곱으로 피팅했다.

- Rs = 213.279972 Ω
- Q = 4.0857237e-05 S·sⁿ, n = 0.731463
- 피팅 구간 상대 복소 RMS 잔차 = 0.2063%
- 하한 500/1000/2000 Hz에 따른 Rs 범위 = 212.766411–213.889788 Ω (신뢰구간 아님)

실측 복소 임피던스에서 Rs만 빼고 2000/2010 Hz를 log(f)로 보간했다.
CPE 전체 곡선을 전극 경계로 강제하지 않았다. 기존 접촉 RC는 이 보정 임피던스로 대체했다.
면적당 임피던스는 `z = Z × 1e-4 m²`이며, 표면 셀 연결 임피던스는 `z / cell_area`다.
PBS 용액 저항을 팬텀 안에 다시 추가하지 않았고 별도의 건식 접촉 저항도 추가하지 않았다.

최상위 후보의 표적값 변화는 +18.91%다. 지표는 방향별 최대 포락선 변조 깊이이며 신경 활성도가 아니다.
6개 시나리오 × 9개 배치 = 54개 조건과 4개 세밀한 격자 계산을 수행했다.
최대 상대 선형계 잔차는 1e-09, 최대 상대 전력 수지 오차는 1.59e-09다.
전극 전류 보존과 층별 전력 합도 검사했다.

## 해석 범위

Rs는 전해액을 주성분으로 가정한 유효 직렬저항이다. 리드·금막·퍼짐저항과의 유일한 분리는 입증되지 않았다.
10 kHz에서도 허수부가 0이 아니므로 고주파 절편을 직접 측정한 값은 아니다.
전 대역 단일 CPE 피팅은 고주파에서 음의 보정 실수부를 만들기 때문에 채택하지 않았다.
PBS 전극 계면을 건식 팬텀 접촉에 적용한 가정 계산이며 추가 건식 접촉 저항은 0으로 두었다.
조직 물성, 공통 GND, 면내 등전위 전극 가정은 기존과 같다. 금막 면내·나노갭 미세구조와 신경 반응은 해석하지 않았다.
표면 최대값은 전극 가장자리 격자에 의존하며 두 격자 비교만으로 수렴이 확정되지 않는다.
