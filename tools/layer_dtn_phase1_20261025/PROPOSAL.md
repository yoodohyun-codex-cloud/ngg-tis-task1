# Phase1 graph/eigen and analytic-depth benchmark

The identical XY0.5mm D50 staircase graph is diagonalized as a real symmetric Neumann Laplacian. Each eigenmode then has an analytic depth solution in the fixed0.1/5/5/15mm scalar layers. This is a reference for vertical discretization conditional on the lateral graph, not an exact continuous-cylinder solution. HREF-MIX and PBS contact uncertainties remain.

Phase1 computes graph, full real eigenbasis and manufactured analytic checks only: **zero CEM conditions and zero CEM/native RHS**. Root must first freeze/publish source and specification, run pure contracts, and admit one numerical child with4CPU/8,000,000,000byte RSS+alltasktmpfs and a600second external watchdog. Python signal handlers cannot reliably stop a blocking LAPACK call; parent termination/kill must act on the child. Finite timeout/resource/numerical failures preserve partial output and give a specific next command; no automatic eigensolve repetition.

The supported installed backend is SciPy real `eigh(driver='evr', overwrite_a=True, check_finite=False)` with a Fortran float64 input. No silent divide-conquer fallback or installation. Input and returned Q each require494,236,800bytes; workspace allowance536,870,912bytes and vector/library allowance268,435,456bytes are estimates, not measured bounds. The input reference is released before diagnostics. A further494,236,800bytes of local Q cache may coexist with resident Q; all owned tmpfs plus RSS remains monitored. Blocking eigen workspace/copies must be measured. No runtime promise follows from array size.

All eigenvectors receive a sparse-graph residual and unit-norm check, in128-column blocks. Orthogonality checks all columns against64 deterministic selected columns; it is explicitly not exhaustive all-pairs checking. Constant nullspace, absence of significant negative/extra-zero modes, real and split-complex transform roundtrips, homogeneous limits, independent bottom-up transfer and stable scaled depth evaluation are preregistered. No full complex Q, complex K, full Q-transpose-Q or dense residual is allocated. The sole roundoff zero eigenvalue is set to zero only after the constant-vector proof.

Eigenvalues, XY/indices/edge arrays, checks, resource receipts, source and Q chunk hashes can be durable scientific output. Exclusive Q cache chunks are at most32MiB, float64 little-endian Fortran columns with exact ranges and local SHA/bytes readback. Q cache remains local recomputable tmpfs and is explicitly not remotely durable; its measured eigensolve cost must be retained. No500MB cache upload is required for phase1. No original files or failure evidence are deleted.

The61,779,600 entries in one dense real eigenbasis are numerical array entries, not physical mesh cells. Both counts are disclosed; this is a newly registered method, not a reinterpretation of the cell cap.
