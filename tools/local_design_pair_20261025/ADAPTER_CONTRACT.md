# Assigned local pair — execution is held

`LOCAL14-c9-diagonal` and `LOCAL16-c8p5-diagonal` are assigned conditionally.
They use the fixed D50 phantom/layers and the same first-eight coarse XY100,
HREF-MIX/PBS contact, two outputs, common returns, 50-ohm source model,
2000/2010-Hz sine carriers, and hybrid field/2074-direction metric definitions.
All four driven RHS are NEW. An eigen cache is reused; no baseline source or
field solution is reused. The Linux first-eight sources and owner are unchanged.

The input manifest contains fixed public commits, repository-relative paths,
safe local-relative destinations, bytes and SHA256. Selection used JSON
metadata only; the preparer did not open graph/field/Q arrays. The copied
`kernel/` files are byte-identical first-eight scientific sources. They retain
historical Linux constants. Their old `build`, `make_spec`, `required_inputs`
and owner/worker are explicitly NOT portable execution interfaces.

`portable_pair.required_inputs(root)` returns expected paths/hashes without raw
reads. `prepare_spec(root, out)` verifies the small material/contact receipts,
generates exact full-face local masks and canonical scientific configuration
hashes, and preserves `execution_permitted=false`, `lease=null`. It grants no
execution permission. `verify_inputs` and `load_graph_and_Q` are owner-called
interfaces; they read raw cache bytes and require an external finite guard.
`scientific_kernel` exposes unchanged low-level profile/solve/field/mask and
metric APIs. It does not call the old Linux build or mutate their globals.
`build_local_case` provides a TWO-RHS case loop using those unchanged functions,
full raw exports and the same raw metrics. It requires a future validated
`owner.assert_active(canonical_config_SHA256)` callback at every guard, the
verified shared cache/graph, actual common grid/weights, and a finite deadline.
No owner implementation or actual execution is supplied by this bundle.
Local raw calculations need not wait for cloud-eight completion: only the
comparison/normalization reference `B0-square15-c10-diagonal` awaits the
authenticated cloud B0 result commit. Neither local case becomes a baseline.
