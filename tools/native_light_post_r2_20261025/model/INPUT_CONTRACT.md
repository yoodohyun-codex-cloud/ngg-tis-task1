# Stored native light postprocess input contract

This new source is inert on import. Its author has not called any model/input function, imported NumPy, decoded arrays, read Q/CSV, run a test, observed a process or performed scientific computation. Root alone may prepare or execute the finite batch. `light_inputs.make_spec(admission=None)` and `required_inputs(admission=None)` defer all metadata authentication until a separate actual positive root decision.

The primary data are the two actual complete fine XY102-Z97 records in public result `fd0b0becc1f38d5c8118c929e7c5c4f24cc64c47`, with source `83a61fb55bd42a8ef778a8653c8aa31bbdf647e0`. The original coarse101-B0 result and source separately authenticate the fixed cutoffs, four distinct existing normalization scales and unchanged material/contact/circuit/ROI definitions. Every selected scalar archive, carrier potential archive and grid/ROI archive has a direct full-file SHA/bytes/readback descriptor. Raw arrays are never decoded here. Q chunks, eigenvectors and PDE/field/angular APIs are not dependencies.

`datasets` contains the two full fine97 scalar cases and may contain the one E13 coarse101 case only after an actual complete ellipse result is fully published and root-reviewed. A published failed ellipse outcome is retained as `ellipse_outcome` with its exact primary record, publication proof and explicit missing fields; it contributes no fabricated field/scalar dataset. A source-only proposal, future fixture or missing publication does not count as an actual result. The optional ellipse source publication and specification are separately authenticated when complete, and its underlying coarse101 common grid must be byte-identical to the original baseline archive. No coarseSC4 patch is treated as a full scalar field.

Each dataset exposes `grid` with key `grid`; `weights` with the six original region-key mappings; `scalars` with key `AM_max2074`; `raw_by_frequency` for 2000/2010 with key `phi_peak_V`; the complete original metadata row and separate existing `normalizations`; and source/result/spec/material/contact/circuit provenance. The graph/depth native ordering is retained. Arrays and normalizations are not recalculated by this helper. The main postprocessor must verify actual array keys, finiteness, coordinates and field dimensions before use and must release arrays between streaming stages to satisfy its separately admitted low-RSS forecast.

The target remains central radius5mm, depth15–20mm, physical top depth0 and positive z downward. Body diameter50mm and layers0.1/5/5/15mm, top4physicalpads/2independentoutputs/common GND/50ohm per output and inactive ideal0V through50ohm remain unchanged. E/J RMS, peak carrier, modulation and native potential difference are distinct quantities. Existing13-of14/contact/edge/interface/material failures, no full convergence, no experiment/activation/safety/adoption and actual instrument-loading uncertainty remain visible.

Two fixed cutoffs are copied from original coarse101-B0: target AM mean and off-target AM P95. They are B0-relative numerical diagnostics selected before this postbatch, after the original PDE; they are not physiological thresholds and were not preregistered before that PDE. No high-volume or probe value is invented by this metadata helper. New solves, Q/eigen, full field reconstruction and angular maxima evaluation counts remain zero. Canonical source-inventory keys always use the fixed `SOURCE` namespace and never `__file__` deployment paths.
