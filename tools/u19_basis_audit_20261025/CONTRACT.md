# Cached actual U19 basis audit

Proposed finite owner stage:60seconds under the existing4CPU/aggregate8e9byte
policy. No actual code/test/data evaluation was performed by source agents.
No old file is modified. Root owns locks, budget accounting, checkpoint,
publication and output persistence.

`required_inputs()` hashes only small metadata and sources, and returns existing
native SHA declarations without reading their arrays. Current result publication
must directly prove raw native files; its readback must authenticate the exact
source-publication document before that older publication can prove config,
material/contact/face/mask inputs. Missing direct raw proof is a blocker.

Root calls `make_spec()` and freezes its JSON before opening native fields.
`build(guard,deadline_monotonic=None,spec=spec)` returns `{summary,arrays}` and
writes nothing. `basis_math.py` is an unchanged copy of actual U19 math source.
Raw complex128LE shapes, finite values, peak+jomega*t, topology and per-frequency
gamma are checked. Source0 is reconstructed and compared with preserved actual
U19 summary; source1 is reported separately. Native layer/contact/50ohm quadratic
losses and source/contact current matrices provide energy/KCL tests for both
actual bases and two same-frequency algebraic cross-term combinations. The
averaged stored E is not falsely integrated as exact native face energy.

The physical mask schema is `pad,i,j,area_m2`, with absolute areas. Native contacts
use `pad,x_mm,y_mm,area_m2`; coordinates are mapped with the actual0.5mm lattice.
Exact typed coordinate/area binding precedes geometric symmetry inference.
Y-reflection with pad0↔1/pad2↔3 is attempted and stays `not_applicable` when the
diagonal source arrangement fails it. A separately predeclared180degree XY
rotation may prove that pad exchange; potential transforms as a scalar and E
parity is(-Ex,-Ey,+Ez). No phase or common-ground gauge offset is fitted. Norms
and maxima are diagnostics without a newly invented symmetry acceptance limit.

Statistics retain original physical-volume ROI weights and128²fractional target
overlap. Target mean/P10/energyRMS, skin vector Jmax/J95, area-weighted contact
Jmax/J95, contact voltage RMS, all four layer/skin/contact/source-resistor/source
powers and both output RMS currents are distinct. Sum output RMS current is
bookkeeping. No TIS is inferred from one carrier, no second-frequency solve is
claimed, and no physiological/safety/material/anatomic/experimental validation
or candidate adoption follows. Existing independent5%failure holds stay intact.
