# 중앙 깊이 20 mm · 5 mm 차동 측정 설정

사용자가 확인한 장비는 **ETA5001 차동 전압 프로브와 Keysight DSOX1202A**이다. 측정 대상은 팬텀 중앙의 깊이 20 mm에서 간격 5 mm인 두 점 사이 전위차이며, X 방향과 Y 방향을 각각 본다. 발생기 출력 단자의 전압과 구분한다. 실제 감쇠 스위치 위치와 현재 스코프 설정은 아직 확인되지 않았다.

기계 판독용 기록은 [probe-measurement-settings.json](../tis-java/electrode-data/probe-measurement-settings.json)에 있다. 여기의 **50×·DC·배율 50:1은 권장 시작 설정**이며 사용자가 이미 선택했다고 기록하지 않는다. 실제 깊이 비교 수치는 별도 검증 결과에서 연결한다.

## 50×와 500×의 역할

프로브는 두 입력의 차동 전압을 감쇠해 BNC로 보낸다. 정상 선형 범위와 지정 출력 부하에서 하드웨어 감쇠비를 A라 하면 `v_BNC(t) ≈ Δv_tip(t)/A`이다. **50×는 50배 증폭이 아니라 1/50 감쇠**, 500×는 1/500 감쇠다. 같은 작은 입력에서 50×의 BNC 신호는 500×보다 10배 크다.

ETA 공식 설명서는 작은 신호에서 높은 분해능과 낮은 잡음을 위해 50×를 쓰도록 설명한다. ETA5001의 차동 범위는 50×에서 ±70 V, 500×에서 ±700 V(DC + peak AC)다. 이 범위는 작은 mV 신호의 검출·정확도를 보증하는 수치가 아니다. [ETA 공식 설명서, PDF 5쪽·8쪽 / 인쇄 7–8쪽·14쪽](https://www.tw-eta.com/index.php?c=file&id=4fa177df22864518b2d7818d4db5db2d&m=down&s=api)

스코프의 Probe 배율 K는 표시와 측정값을 `K × v_BNC`로 환산한다. 하드웨어와 같은 배율을 수동으로 지정해야 한다. DSOX1202A에는 프로브 자동 식별이 없다. 배율 메뉴만 바꾸면 실제 BNC 신호나 ADC 입력의 신호 대 잡음비는 커지지 않는다. [Keysight 공식 사용자 설명서, 32·52–53·266쪽](https://www.keysight.com/content/dam/keysight/en/doc/gate/user-manuals/9018-70020.pdf)

다음 **20 mVpp는 환산 예시**이며 계산값이나 실측값이 아니다.

| 실제 두 tip 사이 ΔVpp | 프로브 스위치 A | BNC에서의 nominal Vpp = ΔVpp/A | 스코프 Probe 배율 K | 스코프 표시 Vpp = K × BNC |
|---:|---:|---:|---:|---:|
| 20 mVpp | 50× | 0.4 mVpp | 50:1 | 20 mVpp |
| 20 mVpp | 500× | 0.04 mVpp | 500:1 | 20 mVpp |
| 20 mVpp | 500× | 0.04 mVpp | 50:1 — 불일치 예시 | 2 mVpp |
| 20 mVpp | 50× | 0.4 mVpp | 500:1 — 불일치 예시 | 200 mVpp |

스코프에 올바른 50:1이 이미 지정됐다면 화면 전압에 50을 다시 곱하지 않는다. 이 표는 프로브의 감쇠·표시 환산이며 발생기의 High-Z/50 Ω 표시 배율과는 별개다.

동일 gain·대역·시간축·취득 모드에서 차동 입력 0인 기준 기록과 실제 신호를 비교해야 측정 가시성을 평가할 수 있다. 이상적인 Δφ 예측값과 실제 측정 성공 여부를 별도로 보고한다. 제조사의 ±2%나 스코프 표시 분해능으로 팁 접촉·잡음·교정·로딩을 합친 측정 신뢰구간을 만들지 않는다.

## DSOX1202A에서 권장하는 시작 설정

확인한 공식 자료는 **1200 X-Series 모델을 포함한 N2137-97038, Fifth edition, August 2022**와 **5992-3484EN, November 12, 2024**다. 이전 DSOX1102A 전용 자료와 구분했다.

| 기능 | DSOX1202A 설정 / 공식 근거 |
|---|---|
| 하드웨어 프로브 | 작은 신호는 ETA5001 50×부터 시작; 실제 선택 여부는 별도 확인 |
| 입력 임피던스 | 아날로그 채널은 고정 1 MΩ ±2%, 16 pF ±3 pF. 내장 50 Ω 전환 메뉴를 찾는 설정이 아님; 외부 50 Ω 종단을 추가하는 조건도 아님 |
| 결합 | `[1]` 또는 `[2] → Coupling → DC` |
| 표시 배율 | 해당 채널 `→ Probe → Units: Volts`, `Ratio → Entry: 50:1`; 프로브를 500×로 바꾸면 500:1로 함께 변경 |
| 대역 제한 | 해당 채널 `→ BW Limit → On`, 약 20 MHz |
| 초기 취득 | `Normal`로 먼저 확인하고, 필요하면 `[Acquire] → Acq Mode → High Resolution` |
| 반복 획득 평균 | `[Acquire] → Acq Mode → Averaging → #Avgs`; 전체 파형의 반복 위상과 안정 트리거를 확인한 뒤 적용 |

메뉴 근거는 [Keysight 사용자 설명서 32·50–53·138–141쪽](https://www.keysight.com/content/dam/keysight/en/doc/gate/user-manuals/9018-70020.pdf), 입력·감도 사양은 [데이터시트 12–13쪽](https://www.keysight.com/content/dam/keysight/en/doc/ungate/data-sheets/5992-3484.pdf)이다.

표시 감도 범위는 BNC 기준 500 μV/div–10 V/div, 기본 수직 분해능은 8 bit다. **500 μV/div는 1 mV/div 설정의 2배 디지털 확대**이며 새로운 아날로그 감도나 검출 보증이 아니다. 50:1 표시 배율에서 500 μV/div에 해당하는 tip 환산 눈금은 25 mV/div다. 검토한 데이터시트·설명서에는 이 측정 조건의 스코프 입력 RMS 잡음을 보장하는 수치 표가 없으므로 임의의 잡음 바닥을 채우지 않는다.

High Resolution은 같은 획득 안의 연속 샘플을 평균하며 시간축에 따라 실효 대역폭을 줄인다. 공식 표의 ≥20 μs/div에서 12 bit는 효과적인 분해능 표기다. Averaging은 안정 트리거가 필요한 여러 획득의 평균이며 횟수 2–65,536을 지원한다. 두 모드는 구분해 설정하고 기록한다. 20 MHz 제한은 ETA5001의 15 MHz보다 높으므로 프로브 자체 잡음이 크게 줄거나 작은 심부 전압이 반드시 보인다고 약속할 수 없다.

## 30 Hz·10 Hz 비트의 기록 시간과 평균

- 현재 3000/3030 Hz TIS의 전체 반복 주기는 **1/30 s = 33.333… ms**다. 기본파의 3차인 9000/9090 Hz도 같은 주기 안에 정수 회 반복된다.
- 2000/2010 Hz 비교 조건은 **1/10 s = 100 ms**이며 6000/6030 Hz도 이 주기에 맞는다.
- 10 ms/div의 10칸 표시 창은 100 ms로, 이상적인 위 주파수에서 30 Hz 비트 3회 또는 10 Hz 비트 1회다. 이는 시간축 시작 예시이며 실제 저장 샘플 수·주파수·구간과 함께 확인한다.

일반적인 한 반송파의 에지로만 트리거한 여러 획득은 다른 반송파의 상대 위상을 매번 같게 하지 않을 수 있다. 그러면 Averaging이 다른 반송파와 비트 포락선을 약화할 수 있다. 이 주의는 공식 설명서의 안정 트리거 조건에 근거한 신호처리 해석이다. 처음에는 Normal 또는 같은 획득 내부의 High Resolution을 사용하고, 여러 획득 평균은 **전체 비트 주기와 반송파 위상 재현**을 확인한 경우에만 쓴다. 스코프 AC 결합의 10 Hz 하이패스가 2–3 kHz 반송파가 만드는 10 Hz 비트 포락선을 그대로 차단한다는 설명도 피한다.

## 팁 전위차와 로딩의 해석

방향 X/Y의 두 팁은 각각 중앙에서 ±2.5 mm, z=20 mm다. 피크 복소 전위가 저장되어 있다면 주파수별 `ΔΦ_f = Φ_f(r+) − Φ_f(r−)`를 먼저 구한다. 시간 파형은 `Δv(t)=Re Σ_f ΔΦ_f exp(+j2πft)`이며, 공통 반복 주기에서 이상적인 총 RMS는 `sqrt(Σ_f |ΔΦ_f|²/2)`다. **Vpp는 이 합성 파형의 최대−최소**로 평가하며 여러 주파수의 RMS에 단일 정현파의 `2√2`를 일괄 적용하지 않는다.

준정전계에서 `ΔΦ_f = −∫ E_f·dl`이고, `−ΔΦ_f/0.5 cm` (V/cm)는 5 mm 경로의 방향 성분 평균이다. 중앙 한 점의 총 벡터 RMS나 방향 탐색 최대 TIS와 같은 값이 아니다. 공간적 변화·방향·복소 위상을 유지해 비교한다.

공식 R/C는 전기적 입력 부하 사양일 뿐 **팬텀 속 tip 접촉과 국소장 교란을 검증한 결과가 아니다**. tip 재질·노출 면적·접촉 임피던스·리드 배치·접지 결합이 정해져야 로딩 오차를 평가할 수 있다. 각 leg 대 접지와 차동 R/C 표기를 독립 소자로 동시에 더해 중복 부하를 만들지 않는다. 스코프의 1 MΩ/16 pF는 능동 프로브 **출력 뒤**의 사양이며 이를 5 mm 팁 사이의 직접 부하로 옮기지 않는다.
