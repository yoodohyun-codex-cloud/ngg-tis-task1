## 측정기 사양 갱신 — 사용자 제공 근거

초기 점검 뒤 사용자가 ETA5001과 Keysight DSOX1202A의 사양을 제공했다. 앞 절의 입력R/C 미확인은 이 추가 사양으로 갱신하되 실제 스위치·메뉴·교정 상태 미확인은 유지한다. ETA5001은15MHz, 입력 사이8MΩ/약3.5pF, 각 입력–접지4MΩ/약7pF,50×/500×다. 두4MΩ/7pF 대지 분기의 차동 등가가8MΩ/3.5pF이므로 별도 차동 분기를 추가해 부하를 중복 계산하지 않는다. 스코프의1MΩ±2%/16pF±3pF는 능동 프로브 출력 측이며 팬텀에 직접 연결하지 않는다.70/100/200MHz 중 실제 본체 옵션은 미확인이다.

권장 시작 조건은50×·스코프50:1·DC coupling·20MHz 제한ON·외부50Ω 없음이다. 이는 실제 사용 기록이 아니다. 팬텀의 두 probe-tip 사이 및 접지 귀환에 대한 복소2×2 포트 임피던스/Green 응답은 현재 source 기저에 없으므로, 입력R/C를 반영한 장의 변화는 미계산으로 남긴다. 무부하 파형의 감쇠·표시 배율과 가정한 대역 전달 함수를 적용한 예측은 별도이며 실측/부하 검증으로 승격하지 않는다. 제조사 URL과 사양 출처는 새 장비 설정과 예측 영수증에 보존하고 권리 미확인 PDF 원문은 복제하지 않는다.
