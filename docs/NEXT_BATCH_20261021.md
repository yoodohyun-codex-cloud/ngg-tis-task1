## 실행 범위와 판정

기존 `physical-pad-burdens.json`, source-bound volume 보고서와 native scalar/grid만 사용한다. 기존 접촉밀도 계산·PDE·방향 탐색·프로브 합성을 중복 실행하지 않는다. 원전압과 `skin_contact_only`를 분리해 위치별 차이, 양/음 변화, 층·깊이·가장 가까운 물리 패드별 공간 연관성을 분석한다. maxTIS는 기본 두 carrier의 유한 방향 최대 변조, RMS는 모든 활성 carrier의 벡터 RMS이며 서로 다른 물리량이다.

공통 좌표·가중치 및 **기준 조건의 고정 mean/P10 cutoff**로 고변조 부피를 비교한다. cutoff는 생리적 역치가 아니다. 최근접 패드 구획은 기술적 공간 연관성이고 소스별 인과 기여가 아니다. nonlinear maxTIS를 소스별로 더하지 않는다. carrier별 E 또는 balance를 읽지 않았다면 해당 분해를 계산했다고 표시하지 않는다.

원인 분석 후, 동일900mm²·4패드·2출력·공통GND의 범위에서 하나의 변수만 바꾼 후보를 최대1개 선택한다. 현재 검토 질문은 **동일 물리 형상·위치에서 신호와 귀환 역할을 교환하는 배선**이며 아직 PDE 실행 등록이 아니다. 현재 불리한 비대칭을 더 미세한 격자로 반복하지 않는다.
