실제 source Vpp는 각 출력과 비교

모든 source Vpp는50 Ω 앞 open/high-Z 전체 합성 파형의 최대−최소입니다. 주파수별 Vpp가 아닙니다. 부하 연결 metal Vpp·접촉 RMS 전압·실제 계측기 loading을 서로 구분합니다. raw/skin8 선택은 TIS 기준 진폭을 뜻하며, C1에는 선택한 RMS에 맞춘 별도 source Vpp를 적용합니다. skin8은 원래8개 피부·접촉 수치 제한만 적용하며 source 전력/1Vpp 상한은 없어 실제 source가1Vpp를 넘을 수 있습니다.

RMS 일치와 공간분포 차이

에너지 RMS=sqrt(가중 평균(E_RMS²))이며 평균 E_RMS와 다릅니다. 두 매칭 정의는 별개이고 선택하지 않은 정의는 일반적으로 일치하지 않습니다. 실제 fractional ROI와 native 표현 체적을 유지합니다. ±10% 분포 비율은 생리적 활성 범위가 아닙니다.

전류밀도·접촉전압·전력의 개별 비교

접촉면 normal J의 면적 가중P95와 피부 체적 벡터 J의 체적 가중P95는 다른 통계입니다. RMS 목표만 맞췄고 전류·전력·접촉면적·피부 부담을 동시에 일치시킨 비교가 아닙니다. 전력이 작아도 접촉 J가 더 높을 수 있습니다. 수치 기준은 인체안전 한계가 아닙니다.
