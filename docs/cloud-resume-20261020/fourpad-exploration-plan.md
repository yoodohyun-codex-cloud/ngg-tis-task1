# 잔차 진단 후 4패드 유한 탐색

새 helper 없이 기존 frozen pool의 6조건을 사용한다. D50 mm, 층0.1/5/5/15 mm, 상부 물리 패드4개·독립 출력2개·공통GND, 출력당 전체 파형 HighZ1Vpp/50Ω, 물성·접촉·3000/3030/9000/9090Hz·위상0/0을 보존한다. 다른 주파수의 비구동 출력도0V/50Ω 종단이다.

| 조건 | 해석적 총면적 mm² | 실제 mask 총면적 mm² | 최소 패치 mm² |
|---|---:|---:|---:|
| equal-circle225 | 900.000000 | 899.999647 | 0.007451927 |
| equal-ellipse24 | 900.000000 | 899.999647 | 0.002713241 |
| equal-rectangle17p5 | 900.000000 | 900.000000 | 0.223214286 |
| equal-rounded18-r3 | 900.000000 | 899.999956 | 0.107808090 |
| adjacent-square15 | 900.000000 | 900.000000 | 1.562500000 |
| free-square10-r12p5xy | 400.000000 | 400.000000 | 1.562500000 |

4개 동일 면적 형상과 신호/귀환 위치 대조, 작은 패드·위치 대조를 구분한다. free-square10은 패드당100mm²·총400mm²·중심±12.5mm로 900mm² 비교와 별개다. 곡선은4096점 내접 polygon이므로 해석적 면적과 미세한 차이가 있으며, 실제 면적·패치 최소/최대·SHA는 JSON에 있다. ellipse 접선 회전과 adjacent의 신호/귀환 배선도 고정 설정 그대로 유지한다.

과거 환경에서는 이미 계산한 형상이다. 누락된 native E/φ를 새 환경에서 다시 만들고 전체 피부 부담·공간 분포를 검증하는 비용으로 기록한다. 특히 rounded를 새 이름으로 중복 생성하거나 새 발견으로 세지 않는다. coarse/xy80/xy100/SC4/bulk baseline은 기존 캐시를 재사용한다.

순서는 coarse6개(h1.25,각88,480cells) → 최대2개 xy80 → 선택1개의 xy100·SC4·bulk 최대3개다. 형상 조건은 최대11개다. 진짜 개선과 격자 게이트를 통과한 경우에만 별도 상한의 C1한 조건을 추가할 수 있어 전체 최대12개이며, 실제 누적 예산이 우선한다. 기존 C1은xy80만 있어 같은 후보의 TISxy80과 정확히 비교할 수 있다. h0.5와 같은 격자 C1에는 추후 별도 registration이 필요하다. xy80 결과를 h0.5 비교나 채택 근거로 바꾸어 표시하지 않는다.

순위는 r≤5mm·깊이15–20mm 부피 ROI의 절대 mean/P10이다. 동일 전압·정확한 동일 총전력·동일 접촉/전원 부담·추가 전체 피부 부담을 각각 보여준다. 실제 피부 손실은 SC+dermis이며 과거 skin_power_W=SC+contact 별칭을 사용하지 않는다. 접촉 법선J와 피부 부피 복소 총전류 벡터J, 면적가중P95와 부피가중P95도 구분한다.

동일 전체 부담에서 ROImean/P10이 모두 같은 격자 baseline 이상이고 적어도 하나가 기존1e-7 상대 재현 허용치를 넘어 증가해야 잠정 개선이다. 표적/표층·전체 비표적 P95 대비 우세도, 고정 baseline 역치의 표적 밖 고변조 부피 및 비표적 최대가 악화되면 제외한다. 전역 최대 위치·깊이곡선·전체 부담과 각 출력 전류도 함께 본다. 전체 피부 audit가 없으면 해당 순위는 unavailable이며 채택하지 않는다.

개선이 없으면 가장 유망한 대조를 수치 진단용으로만 세분하고 baseline이 최신 기준으로 남는다. 진짜 개선과 후보 격자 검증이 없으면 최신 프로브·C1 후보 갱신을 주장하지 않는다. ROI1%·J/접촉전압5%·손실2% 및 기존 native 게이트를 사후 완화하지 않는다. 유한 XY/SC/bulk 비교의 통과만으로 연속체 수렴·실험 검증·깊이 집중 성공을 선언하지 않는다.

잔차 배치가 먼저다. 자원은1CPU·단일 잠금·조건당600초·누적6600초·800,000cells·heap2GiB·전체RSS3GiB·디스크 예약2GiB다. 과거6coarse는약268초였으며 전체 후속 예상은2000초 이내지만 보장값이 아니다. 12×600초를 현재 남은 예산으로 전부 예약할 수 없으므로 각 단계 전에 live 원장을 확인하고 최대 소요가 들어가는 유한 prefix만 실행한다. 부족한 조건은 not_run_budget으로 보존하고 예산·예약 공간·팬텀을 늘리지 않는다.

검토한 geometry API는 validate_design와mask(design,h)이며, 이번6조건에는 이미 생성된 frozen마스크를 사용한다. CLI명령·후속지원caseID·설정/마스크SHA는 JSON에 있다. 이 계획 작성에서는 helper수정·prepare·컴파일·PDE·커밋을 하지 않았다. PBS 계면의 피부 접촉 불확실성·Rs 차감·면적1회 적용은 별도 후속 질문으로 보존한다.
