# CV 측정 설정 사진과 보존 데이터 대조

사용자가 CV에 사용한 설정 사진을 제공하고 **‘사진 설정이 모든 곡선에 공통 — 차이는 추가 확인 필요’**라고 확인했다. 따라서 각 bare·50 nm·100 nm 곡선의 **공통 명목 scan rate는 0.1 V/s = 100 mV/s로 사용자 확인되었다.** 이전의 ‘scan rate 미상’은 사진 제공 전 정보 상태이며 현재 정보로는 정정한다. 사진의 전압 범위·예상 점수와 기존 Prism 데이터의 불일치는 별도 미해결 항목으로 유지한다. 이 불일치 때문에 사용자 확인된 공통 설정의 연결 자체를 보류하지 않는다.

구조화된 근거와 대조 결과는 [cv-measurement-settings.json](../tis-java/electrode-data/cv-measurement-settings.json)에 있다. 이 문서와 JSON만 새로 작성했으며 원본 pzfx, 기존 paired CSV/profile, run 입력·GUI·solver 결과를 변경하지 않았다. 새 시뮬레이션·워커·모델을 실행하지 않았다.

## 1. 사진에서 제공된 값

사진은 현재 대화의 inline 자료다. 이 감사에는 로컬 원본 이미지 경로나 이미지 파일 hash가 없으며, 대화에서 전달된 설정값과 모든 곡선에 공통이라는 사용자 확인을 보존한다. ‘사용자가 확인한 공통 명목 설정’과 ‘원시 시간 기록으로 독립 검증한 실제 dV/dt·전체 프로토콜 재현’을 구분한다.

| CV staircase 항목 | 제공된 표시값 |
|---|---:|
| Start potential | 0 V_REF |
| Upper vertex | +1 V_REF |
| Lower vertex | −1 V_REF |
| Stop potential | 0 V_REF |
| Scans | 1 |
| Scan rate | **0.1 V/s** |
| Step | **0.00244 V** |
| Interval | **0.0244 s** |
| Estimated points | **1640** |
| Estimated duration | **40.016 s** |
| Stop crossings | 2 |

표시 순서는 **Apply 0 V → Cell on → Wait 5 s → CV → Cell off**다. `0.00244 V / 0.0244 s = 0.1 V/s`, `1640 × 0.0244 s = 40.016 s`로 표시된 설정끼리는 수치상 일관된다. 이는 설정값의 내부 일관성 검사이며 실제 취득 시간 벡터의 검증이 아니다.

하단에 선택된 **Chronopotentiometry fast의 한 Step**은 다음과 같다.

| 선택 Step 항목 | 제공된 표시값 |
|---|---:|
| Duration | 0.01 s |
| Interval | 0.0001 s |
| Estimated points | 100 |
| Current | 0 A |

다른 Step은 공개되지 않았다. 이 한 Step으로 전체 전류 펄스·분극·회복 프로토콜이 정해졌다고 판단하지 않으며, 0 A 설정을 전하 주입 시험이나 CIC 측정 근거로 사용하지 않는다.

## 2. 원본·CSV·현재 plot 데이터의 독립 대조

보존 원본은 [pedot cic.pzfx](../tis-java/electrode-data/cv-source/pedot%20cic.pzfx)이며 실제 파일 형식은 XML이 아닌 `PCFFGRA4` 바이너리다. SHA-256은 `d1c6c74591a810dbb569f663bfc67e5b13256f13d4a50f826c96d8934614c369`다. 해당 run의 보존 사본과 byte 단위로 일치한다.

기존 추출 함수를 실행해 결과 파일을 다시 쓰지 않았다. 대신 원본의 열 이름 token, count/length 및 12-byte `<IIf` record를 별도로 읽어 index·potential·bare current·PEDOT current 네 열을 재구성했다. 이를 다음 보존 CSV와 현재 `cv-profile.json`의 plot 배열에 대조해 **모든 유효 행의 네 열이 수치상 정확히 일치**함을 확인했다.

- [50 nm paired CSV](../tis-java/runs/explore-20261017T133224038032Z/inputs/cv-paired-50nm.csv)
- [100 nm paired CSV](../tis-java/runs/explore-20261017T133224038032Z/inputs/cv-paired-100nm.csv)
- [기존 CV profile](../tis-java/runs/explore-20261017T133224038032Z/inputs/cv-profile.json)

| 대조 항목 | 50 nm paired 표 | 100 nm paired 표 |
|---|---:|---:|
| 원본 X/bare/PEDOT 열 각각의 record 수 | 1476 | 1477 |
| 각 열의 마지막 type-0 blank 수 | 0 | 1 |
| 기존 추출 규칙의 유효 paired 행 수 | **1476** | **1476** |
| 실제 최저 potential | **−0.8007799983024597 V** | **−0.8007799983024597 V** |
| 실제 최고 potential | **+1.0009770393371582 V** | **+1.0009770393371582 V** |
| 첫 기록 potential | +0.002440999960526824 V | +0.002440999960526824 V |
| 마지막 기록 potential | 0 V | 0 V |
| 상한 반전점의 0-based index | 409 | 409 |
| 하한 반전점의 0-based index | 1147 | 1147 |

두 표의 potential 배열은 같지만 **bare 전류 곡선은 서로 다르다**. bare 곡선을 합치거나 두 코팅의 절대 우열을 동일 시편 반복 실험으로 해석하지 않는다. 원본의 record type/format flags를 보존했다. 50 nm 표의 bare 열에는 type 5가 10개, 100 nm 표의 bare 열에는 8개 있다. 기존 복원은 type 0만 빈 값으로 제외했으며, 이 format-specific 복원의 의미를 vendor가 검증한 공식 XML export와 동일하게 보증하지 않는다.

## 3. 사진과 데이터의 일치·불일치

**전압 하한과 점수가 일치하지 않는다.** 사진의 lower는 −1 V_REF이고 예상 점수는 1640이지만, 두 기존 곡선의 하한은 약 −0.80078 V, 유효 점수는 1476이다. 예상값보다 **164점 적다**. 100 nm 표에 있는 blank 한 행으로는 이 차이를 설명할 수 없다. 최고값은 약 +1.000977 V로 표시된 +1 V와 가깝지만, 이것만으로 전체 프로토콜이 같다고 판정하지 않는다.

전압 증분의 크기는 표시 Step과 가깝다. 두 표에서 연속 전압 차이 절댓값의 중앙값은 **0.0024409890174865723 V**, 최소–최대는 **0.0024399757385253906–0.0024500489234924316 V**다. 사진의 interval 0.0244 s를 같은 기록에 적용한다고 가정하면 중앙값 비율은 **0.10004053350354804 V/s**다. 이는 표시된 0.1 V/s와 수치상 근접하지만 **조건부 계산**이며 실제 scan rate의 독립 측정이 아니다.

복원된 열에는 시간 벡터·취득 시각·해당 instrument method 파일 연결이 없다. 사용자는 공통 설정임을 확인했지만 전압 범위·점수 차이의 원인은 추가 확인이 필요하다고 했다. 이 원인은 현재 원시 기록만으로 구분할 수 없다. 따라서 다음과 같이 근거 상태를 유지한다.

| 항목 | 현재 상태 |
|---|---|
| 표시된 CV 프로토콜의 scan rate | **0.1 V/s = 100 mV/s** |
| 표시 Step/interval/scan rate의 내부 일관성 | 일치 |
| 기존 record → CSV → plot 데이터 전사 | 정확히 일치 |
| 사진과 기존 곡선의 전체 전압 범위·점수 | 불일치 |
| 각 bare·50 nm·100 nm 곡선에 공통 명목 0.1 V/s 배정 | **사용자 확인 완료** |
| 사진의 명목 ±1 V·1640점 전체 프로토콜의 원기록 재현 | **불일치 미해결·추가 확인 필요** |
| 기존 plot의 실제 dV/dt 독립 확인 | 시간 데이터가 없어 미확인 |

전압 V·전류 A·노출 면적 **1 cm²**는 이전 사용자 확인을 유지한다. Ag/AgCl 기준전극·Pt 상대전극은 잠정 정보다. 사진의 `V_REF`라는 라벨만으로 기준전극 종류가 확인된 것은 아니다.

## 4. 적분으로 할 수 있는 일과 현재 보류할 일

현재 profile에 있는 것은 전체 복원 경로의 `∫|I| |dV|`이며 단위는 **A·V**다. 이는 CV 모양의 비교 지표로 보존한다. 특정 cathodic/anodic branch·전압 구간·전류 부호·기준선 처리 규약을 정한 CSC와 같지 않다.

| paired 표 | 기존 bare `∫|I| |dV|` A·V | 기존 PEDOT `∫|I| |dV|` A·V |
|---|---:|---:|
| 50 nm | 0.0002830871671620936 | 0.0014925948825418242 |
| 100 nm | 0.0006263585119620119 | 0.0031968931053447287 |

공통 명목 scan rate `ν=0.1 V/s`는 사용자 확인되었다. 향후 명시적으로 선택한 branch/실제 기록 전압 구간에 대해 `Q/A = (1/(Aν)) ∫ I(V)|dV|` 형태의 면적당 전하를 검토할 수 있다. cathodic/anodic 구분·부호·적분 branch·누설/기준선 정책·노출 면적과 단위를 함께 명시해야 한다. 현재 데이터에 없는 −1 V부터 약 −0.80078 V까지의 구간을 덧붙이거나 외삽해 채우면 안 된다.

**이번 업데이트에서는 적분 전하·CSC 숫자를 새로 계산·출판하지 않는다.** 공통 scan rate 확인과 별개로 CSC의 branch/부호/기준선·record flags 처리 규약 및 사진의 명목 전체 전압 구간 재현은 보류한다. 향후 적분을 하더라도 실제 기록된 전압 구간의 결과와 사진의 명목 ±1 V 프로토콜 결과를 혼동하지 않아야 한다.

**CIC와 안전창은 계속 미검증이다.** 사진의 upper/lower는 프로그램에 입력된 스캔 한계이며 가역성·수분해·전극 안정성을 검증한 전기화학 창이 아니다. 스캔 속도 하나가 새로 확인되었다고 CV 면적을 자극 펄스 CIC·안전 전압·안전 전류로 바꾸지 않는다. 선택된 0 A chronopotentiometry Step도 이런 근거를 제공하지 않는다.

후속 GUI/입력 연계 시 **‘공통 100 mV/s 사용자 확인·원기록 범위/점수 불일치 추가 확인’**으로 표시한다. 원기록은 약 −0.80078~+1.000977 V·1476점, 사진은 명목 −1~+1 V·예상 1640점으로 구분한다. 원시 timestamps가 없어 독립 dV/dt 검증은 하지 못했다. 보존된 run의 과거 `scan_rate_V_s: null` 및 옛 경고를 이번 감사에서 덮어쓰지 않았으며, 신규 JSON이 사용자 확인과 원기록 일관성 상태를 분리한다.
