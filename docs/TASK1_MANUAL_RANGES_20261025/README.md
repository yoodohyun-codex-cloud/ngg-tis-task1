# 사용자 수동 눈금 GUI

각 수치 그래프 아래 **눈금 직접 조절**을 열고 최소·최대값을 입력한 뒤 적용합니다. 전체 전기장/J 색상, 파형/프로파일 축, 공간 x/y/z 좌표는 위 공통 설정에서 함께 적용할 수 있습니다. 개별 설정은 공통값보다 우선하며 단면·방향·구동·시간 프리셋 변경으로 초기화되지 않습니다.

- 지도: 좌표 X/Y 범위와 색상 최소/최대.
- 파형: 실제 시간 시작/끝과 비대칭 전기장 y축 범위.
- 프로파일: 위치 축과 전기장 y축 범위.
- 전극 상면 배치도: X/Y 표시 범위. 팬텀이나 전극 치수를 바꾸는 기능이 아닙니다.
- 설정 JSON 저장·불러오기, 개별/전체 초기화.

총22개 2D 수치 그래프·배치도에 조절기를 제공합니다. 두 등각 그림은 수치 축이 없는 위치 설명도입니다. 시간축 변경은 기존 복소 phasor를 해당 시각에서 합성하며 최대40001표시점을 사용합니다. 긴 시간 창의 표본 제한은 별도로 표시합니다. 색·축 범위 밖 값은 개수/빗금으로 알리고 hover·수치표에는 원값을 유지합니다. 표본 개수를 3D 부피나 생리적 역치로 해석하지 않습니다.

기본값은 이전 범위2000V/m/20A/m²이며 사용자 입력을 금지하는 상한이 아닙니다. 변수 변경에 맞춰 자동 확대하지 않습니다. 비음수 색 범위, 유한 min<max를 검사하며 잘못된 입력은 적용 전 거부합니다. log1p 색상은 선택한 최소값을 뺀 값에 적용합니다.

검증: 수식·설정/소스15검사,22개 실제 입력 폼,120개 변수 조합에서 유지,10–20ms 시간 이동,잘못된 범위의 원자적 거부,설정 export/import,모바일390px,JS오류·외부요청0. 최초 준비에서 런타임 생성 그룹을 정적 HTML로 찾는 검사 실패를 보존하고 수정했습니다.

기존 packed 과학 데이터·Float64 통계·원본·실패·수렴 보류를 보존했습니다. 이 GUI 단계의 새 PDE/원시 복소장 decode는0입니다. SC/dermis/fat/muscle 전 층 물성 재계산 지시는 별도 근거표·새 민감도 PDE로 추적하며 이 화면으로 완료 처리하지 않습니다.

Windows 저장은 Save-TIS-Results.ps1을 로컬에서 실행해야 합니다. 실제 C: 연결,Windows 저장,OneDrive 동기화는 확인되지 않았습니다. 로컬 경로는 공개 파일에 넣지 않습니다.
