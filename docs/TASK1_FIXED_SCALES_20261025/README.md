# Task1 모든 조건 고정 눈금 GUI

최신 index.html은 기존 과학 데이터·원본을 보존하고 세 GUI 계층의 표시 눈금과 색 변환을 통일합니다.

| 표시 | 고정 범위 |
| --- | --- |
| Carrier/total RMS, 방향별 변조, 순간 전기장 지도, 선 프로파일 | 0–2000 V/m |
| 네 지점 파형의 y축 | −2000–2000 V/m |
| 접촉 normal J RMS 지도 | 0–20 A/m² |
| 수평 좌표 | −25–25 mm |
| 깊이 좌표 | 0–25.1 mm |

범위는 두 조건, 두 구동 기준, 두 RMS 매칭, 일곱 단면과 모든 위상/시간을 포괄하는 복소 벡터 삼각부등식 상한과 기존 Float16 표시 최대·Float64 부피 RMS 최대를 포함해 한 번 계산했습니다. 가장 큰 등록 전기장 상한1097.3069185004485 V/m을 1/2/5 단위로 올려2000 V/m에 고정했습니다. fixed-scale-contract.json에 범위·좌표·출처·증거가 있습니다. 아직 저장하지 않은 공간장의 순간/변조 최대를 검증했다는 뜻은 아닙니다.

단면·깊이·방향·시간·주파수·구동·RMS 매칭 변경으로 범위가 재조정되지 않습니다. 선형/log1p 선택은 모든 전기장 지도에 함께 적용되어 같은 V/m 값은 같은 색입니다. 전류밀도는 별도 A/m² 단위의 선형 고정 눈금입니다. 표층 최대를 포함한 전범위이므로 작은 깊이 값과 파형은 선형 축에서 작게 보일 수 있으며, 자동 확대하지 않습니다. Hover 및 기존 Float64 수치표는 원값을 유지합니다.

XY는+y위쪽, 수직 단면은+z깊이 아래쪽입니다. 프로파일 좌표틀은 실제 팬텀 범위로 고정하고 계산된 셀 중심을 그대로 그립니다.

검증: 단위/회귀13검사, 실제 화면616조건(논문형336/순간장252/원RMS28),18canvas의 고정 범위,6개같은값 RGB 비교,좌표 방향/물리 범위,모바일390px,JS오류·외부요청0. 최초 범위 고정안의 검증 증거는 보존했으며 최종판은 색 변환까지 동기화했습니다.

새 PDE·원시 복소장 decode·새2074방향 검색·새 fat 계산은 없습니다. 기존 packed 과학 데이터와 Float64 통계, 격자/접촉 실패·불확실성 및 수렴/실험/채택 보류를 유지합니다. 기존 GUI는 덮어쓰거나 삭제하지 않았습니다.

Windows 저장은 별도 Save-TIS-Results.ps1을 로컬에서 실행해야 합니다. 클라우드 C: 연결과 실제 Windows/OneDrive 저장·동기화는 미확인입니다.
