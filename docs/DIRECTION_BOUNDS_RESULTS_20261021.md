# Native XYZ 및 연속 방향 경계 결과 — 2026-10-21

원래 사각 패드를 제외한 7개 조건 모두에서, 원래 기준의 피부·접촉 8개 부담을 적용한 `skin_contact_only` 조건에 적어도 한 개의 **조건부 방향 강건 실패**가 확인되었다. 외곽 square3h는 연속 방향 최대값의 상한을 고려해도 목표 ROI 평균·P10이 기준 하한보다 낮았다. 음의 교차 구동 5개는 목표 지표가 높아졌지만 모두 전체 비표적 영역의 P95에서 실패했다. 채택된 후보는 없다.

근거는 [완료 집계 JSON](cloud-direction-bounds-20261021T191000Z/summary.json), [사전등록](cloud-direction-bounds-context-20261021T191000Z/preregistration.json), [root 결정](cloud-direction-bounds-context-20261021T191000Z/decision.json)이다. 이 문서는 완료된 JSON만 읽어 작성했다. 8개 개별 summary JSON을 집계 JSON과 대조하고 JSON 바이트 SHA256을 계산했다. NPZ를 열거나 재해시하지 않았으며 E·grid·φ·고조파 배열을 새로 읽지 않았다. NPZ SHA256은 완료 JSON에 기록된 값을 [별도 근거 목록](DIRECTION_BOUNDS_RESULTS_20261021.json)에 인용했다. 아카이브 자체의 별도 재해시·복구 검증과 이 문서 작성은 구분된다.

실행 상태는 `calculated_supplemental_unadopted`, 소스 커밋은 `46b2fec6d55d438526867b9120fcbd8302caad3c`이다. 계산 시간은 54.907902초, 최대 RSS는 379,547,648바이트(약 362 MiB), CPU는 1개였다. 신규 PDE와 프로브 계산은 0회이며 입력 보존·정규화 불변·기존 판정 불변이 기록되었다. 누적 예산 한도는 승인된 13,800초이며 이 배치가 한도를 확대하지 않았다.

팬텀 D50 mm, SC/dermis/fat/muscle 두께 0.1/5/5/15 mm, 위쪽 부착, hXY=0.625 mm·SC 2셀·bulk 14/14/40(351,680셀)을 유지했다. 4개 물리 패드, 독립 출력 2개, 출력별 50 Ω, 공통 GND이다. 외곽 패드는 각각 576개 native 격자 접촉면의 합집합인 225 mm² 패드로 총 900 mm²이며 형상·위치의 결합 변경이다. 매끄러운 원호나 단독 형상 효과를 뜻하지 않는다.

아래 표는 각 조건에 대해 이전 결과에 저장된 `skin_contact_only` 공통 진폭 배율 A를 그대로 사용한다. 이 모드는 원래 사각 패드의 8개 피부·접촉 부담을 사용하고 source power 및 1 Vpp ceiling은 포함하지 않는다. A는 해당 raw 파형에 대한 공통 배율이며 모든 출력의 실제 Vpp와 같은 값으로 해석하면 안 된다. 전압·전류·전력·부담과 5개 모드의 배율을 다시 최적화하지 않았다.

전체 비표적은 primary ROI를 제외한 모델 전체(`primary_complement`), 표면은 깊이 0–5 mm이다. 외곽 square3h의 평균 상한 3.795334 V/m은 기준 평균 하한 4.061849 V/m보다 낮고, P10 상한 3.476087 V/m도 기준 하한 3.645736 V/m보다 낮다. 따라서 이 고정 모델·정규화에서 목표 손실은 방향 표본을 연속 방향으로 보완해도 남는다. 외곽 sine 대조군도 평균 상한 4.028391 V/m으로 기준 평균 하한에 못 미치고 전체 비표적 P95가 높다.

음의 교차 구동 r=0.05·0.1은 전체 비표적 P95에서, r=0.2·0.5·1은 표면 P95와 전체 비표적 P95에서 조건부 방향 강건 실패가 확인되었다. 예를 들어 r=1의 비표적 P95 하한은 67.248625 V/m으로 기준 상한 23.500215 V/m보다 높다. 목표 평균 증가만으로 깊이 집중을 판정할 수 없다.

XYZ는 각 고정 축에 투영한 별도의 기본파 변조 폭이다. X/Y는 팬텀의 수평 로컬 축이며 Z는 표면 z=0에서 깊이 +z 방향이다. 신경·근육·생리학적 방향으로 등록된 축이 아니고, XYZ 값을 더해 최대 방향 변조로 만들 수 없다. 각 셀에서 최대 방향을 고르는 지표는 하나의 실제 신경 경로도 의미하지 않는다.

복소 peak 전기장 두 개에 대해 `Ai=Re(Ei)Re(Ei)^T+Im(Ei)Im(Ei)^T`를 만들고, λ=0,1/8,…,1의 고정 격자에서 `U=2√minλ eigmax(λA0+(1−λ)A1)`를 계산했다. 모든 실수 단위 방향에 대해 min 투영 제곱은 이 혼합 행렬의 최대 고유값 이하이므로 상한이 성립한다. 정확한 연속 최댓값, 최적 λ 또는 minimax 등호를 주장하지 않는다. 기본파 3000/3030 Hz에만 적용하며 기존 square의 고조파 RMS·원시 파형·프로브 결과를 바꾸지 않았다.

고유값 단위의 FP 여유는 `64·eps·max(Frobenius(A0),Frobenius(A1))+1e−24`이며 raw U와 여유를 둔 U를 별도 저장했다. 기존 L≤U 검사는 상대 1e−10/절대 1e−12 V/m을 사용한다. 허용된 반올림 역전은 상한만 L까지 넓히도록 설계되어 있으나 실제 8개 조건에서 넓힌 셀은 0개였다. 8개 조건의 XYZ primary 평균·P10 회귀 및 L/U 일관성 검사는 모두 통과했다. 이 수치 여유는 정식 IEEE 구간 인증이나 PDE 오차·격자·접촉 모델의 증명이 아니다.

고변조 부피는 기존 사각 패드 L에서 고정한 primary/wholeXY 보조 ROI 평균·P10 cutoff를 그대로 사용한다. A를 먼저 적용한 뒤 `Vol(A·L≥c) ≤ Vol(A·M≥c) ≤ Vol(A·U≥c)`를 보고한다. U 자체에서 cutoff를 다시 만들지 않았다. cutoff는 수치 비교 수준이며 인체 안전·활성화 기준이 아니다. U 지도에서 가장 큰 위치가 실제 최대 변조 위치라고 단정하지 않는다.

이 결론은 저장된 두 native 기저와 8개 고정 구동 조건·5개 고정 정규화에 한정된다. 다른 연속 구동 계열이나 모든 전극 형상의 불가능성을 뜻하지 않는다. XY/SC/bulk·전극 가장자리·접촉 수렴성, 외곽 패드의 약 0.02345 mm rim 여유 민감도, PBS 기반 계면의 실제 피부 검증, 전원 동기화·흡수 전력 처리·계측 부하와 실험 검증은 보류 상태이다. COMSOL 5.3a(예정 5.3.1.201) 설치·실행도 이 결과로 검증되지 않는다.
